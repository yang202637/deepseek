# 辰光Agent平台 — Agent管理页面 UI原型设计说明书（补齐版）

> 本文档是对 `docs/ui/rbac/v2_agents.html` 页面原型的补齐说明，重点描述「创建 Agent」完整流程的实现与交互设计。
> 设计依据：[02-Agent管理.md](../../../app/docs/02-Agent管理.md)（创建/编辑 Agent 表单字段规范）。

---

## 1. 背景与目标

### 1.1 问题

原 `v2_agents.html` 页面中「创建 Agent」按钮仅弹出一个 `alert('创建Agent弹窗')` 提示，没有实际的创建流程，页面属于未完成状态。

### 1.2 补齐目标

1. 实现完整的「创建 Agent」弹窗表单，覆盖 02-Agent管理.md 中定义的全部字段分组（基本信息 / 模型配置 / 知识库配置 / 工具配置 / 高级配置）。
2. 实现真实的增删改查交互：创建后新增记录、编辑回填、删除确认、启动/停止切换、多条件筛选、分页。
3. 补齐空态展示、Toast 反馈、表单校验等完整交互闭环。

## 3. 创建/编辑 Agent 弹窗设计

### 3.1 弹窗结构

- **弹窗宽度**：760px（居中，超出可滚动）
- **Header**：标题（创建 Agent / 编辑 Agent）+ 关闭按钮，吸顶
- **Body**：5 个分区，按顺序纵向排列
- **Footer**：`取消` / `保存草稿` / `创建并发布`（编辑时为 `保存修改`），吸底

### 3.2 表单分区与字段

#### ① 基本信息

| 字段 | 控件 | 必填 | 校验 |
|------|------|------|------|
| Agent名称 | 文本输入 | ✅ | 2-50 字符 |
| Agent类型 | 下拉选择 | ✅ | 对话型/工具型/分析型/创作型/工作流 |
| Agent描述 | 多行文本 | ✅ | 最多 200 字符 |

#### ② 模型配置

| 字段 | 控件 | 必填 | 默认值 |
|------|------|------|--------|
| 关联模型 | 下拉选择 | ✅ | GPT-4 |
| Temperature | 滑块 | — | 0.7（实时显示数值） |
| Max Tokens | 数字输入 | — | 4096 |
| Top P | 数字输入 | — | 1.0 |
| 系统提示词 | 多行文本 | ✅ | — |

#### ③ 知识库配置

| 字段 | 控件 | 默认值 |
|------|------|--------|
| 启用 RAG | 开关（Toggle） | 关 |
| 关联知识库 | 胶囊复选框（Chip） | 未选中 |
| 检索策略 | 下拉选择 | 混合检索 |
| Top K | 数字输入 | 5 |
| 相似度阈值 | 滑块 | 0.7 |

#### ④ 工具配置

| 字段 | 控件 | 默认值 |
|------|------|--------|
| 启用工具调用 | 开关（Toggle） | 关 |
| 可用工具 | 胶囊复选框（Chip） | 未选中 |

#### ⑤ 高级配置

| 字段 | 控件 | 默认值 |
|------|------|--------|
| 开场白 | 文本输入 | 空 |
| 建议问题 | 动态列表（可增删） | 1 条空输入框 |
| 对话轮数限制 | 数字输入 | 20 |
| 超时时间（秒） | 数字输入 | 30 |

### 3.3 交互控件规范

**开关（Toggle）**：44×24px 胶囊，开启为蓝色，带滑块动画（`translateX` 过渡）。

**胶囊复选框（Chip）**：圆角 20px，未选中为灰底灰字，选中为蓝底蓝字（`--accent-light` + `#1E40AF`），点击整块切换选中态。

**滑块（Slider）**：`accent-color` 使用主色，右侧以蓝色小标签实时显示当前数值。

**建议问题**：动态列表，支持添加（追加输入框并聚焦）与删除（仅剩一条时清空而非删除，保证至少一条）。

### 3.4 表单校验

提交时前端校验必填项，失败时通过 Toast 红底提示具体原因：

| 校验项 | 提示文案 |
|--------|---------|
| 名称为空 | 请填写 Agent 名称 |
| 名称过短 | Agent 名称至少 2 个字符 |
| 描述为空 | 请填写 Agent 描述 |
| 系统提示词为空 | 请填写系统提示词 |

## 4. 列表交互设计

### 4.1 工具栏筛选

- 关键词搜索：按名称/描述模糊匹配，输入即时触发（`input` 事件）
- 类型筛选：全部/对话型/工具型/分析型/创作型/工作流
- 状态筛选：全部/运行中/已停止/草稿/异常
- 任一筛选变化时重置到第 1 页

### 4.2 行操作

| 操作 | 触发 | 行为 |
|------|------|------|
| 停止 | 运行中状态 | 切换为已停止 + Toast |
| 启动 | 已停止状态 | 切换为运行中 + Toast |
| 发布 | 草稿状态 | 切换为运行中 + Toast |
| 重启 | 异常状态 | 切换为运行中 + Toast |
| 编辑 | 任意 | 打开弹窗回填数据 |
| 删除 | 任意 | `confirm` 二次确认后删除 + Toast |

### 4.3 空态

无匹配结果时，表格显示居中空态：主文案「未找到匹配的 Agent」+ 副文案「调整搜索关键词或筛选条件，或创建一个新 Agent」。

### 4.4 Toast 反馈

- 右上角固定定位，叠放展示
- 成功：深绿底（`#065F46`）+ ✓ 图标
- 失败：深红底（`#991B1B`）+ ✕ 图标
- 2.5 秒后淡出

## 5. 设计亮点

1. **分区标题带蓝色竖条**：`::before` 伪元素生成 3px 蓝色竖条，清晰划分表单逻辑区块，呼应 02 文档中的"基本信息/模型配置/知识库配置/工具配置/高级配置"五段式结构。
2. **表单双列网格**：基本信息与模型配置采用 `1fr 1fr` 双列，长字段（描述、提示词）独占整行，兼顾密度与可读性。
3. **开关 + 胶囊组合**：RAG/工具开关与知识库/工具选择形成"启用—选择"的自然关联，降低认知负担。
4. **状态驱动按钮文案**：行操作按钮随状态动态变化（停止/启动/发布/重启），一键切换状态，避免多级菜单。
5. **统计卡片实时联动**：创建、删除、启停后，顶部 4 个统计卡片数值即时更新。

## 7. 技术规范

- **实现方式**：纯 HTML5 + CSS3 + Vanilla JavaScript，无外部依赖
