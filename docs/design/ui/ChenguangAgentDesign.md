# 辰光 Agent 设计原型与文档

> 本设计针对 **辰光 Agent**——企业级智能 Agent 管理平台。核心目标是
> 
> * **辨识性**：打破通用 SaaS 卡片风格，提供与业务高度契合的视觉体验。
> * **可用性**：关注信息层级、交互细节，确保管理人员能快速定位与操作。
> * **一致性**：统一配色、排版与组件语义，形成完整的产品语音。

---

## 1. 设计系统核心

| 维度 | 设计决策 | 备注 |

## 2. 视觉关键体验

1. **左侧导航**：垂直布局，节能「悬停 + 选中」交互；徽标放左侧顶部。
2. **页头面包屑**：灰色文字，右侧 Breadcrumb 采用 `>` 代替 `·`，简洁易读。
3. **数据统计卡片**：采用测距卡片、表格相结合，统计卡片用温暖点缀色，表格文字采用暗色系。
4. **列操作**：操作按钮隐藏在 hover 时出现，避免被误操作；删除按钮采用红色文本但不带背景，以降低误触。

## 4. 交互细节

| 场景 | 交互 | 说明 |
|------|------|------|
| 侧栏展开折叠 | 鼠标悬停 / 移动端点击 | 通过 `transform:translateX(0) / -240px` 与 `transition:transform .2s` 实现；未展开时仅显示图标 |
| 行点击事件 | 点击整行跳转至详情 | 不再点击单独的 Edit/Delete 按钮；按钮仍在行尾作为单独操作 |
| 搜索输入 | 按回车或 500ms 延迟 | 防止频繁请求，在触发前取消前一次请求 |
| 词条删除 | 删除按钮 + 确认弹窗 | 弹窗字体简洁、确认按钮亮红 |
| Form 校验 | Blur 校验 & 实时错误提示 | 交互性同时提供即时反馈 |

## 5. 可访问性

* 色弱友好：使用 WCAG AA 级可比度 ≥ 4.5:1。
* `prefers-reduced-motion`：开启时仅保留移动可操作与页面加载动画。
* 语义化标签：`<header>`, `<nav>`, `<main>`, `<section>` 等均已按需使用，提升屏幕阅读器体验。
