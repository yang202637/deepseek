# 辰光Agent平台 — 用户管理页面 UI原型设计说明书（补齐版）

> 本文档是对 `docs/ui/rbac/users.html` 页面原型的补齐说明，重点描述「新增用户」完整流程的实现与交互设计。
> 设计依据：[09-系统管理.md](../../../app/docs/09-系统管理.md)（用户管理章节）+ [PROJECT_SPEC_V2.md](../../spec/PROJECT_SPEC_V2.md)（RBAC 数据范围规范）。

---

## 1. 背景与目标

### 1.1 问题

原 `users.html` 页面中「创建用户」按钮虽有弹窗，但**提交按钮未绑定任何逻辑**，表格为写死的静态 HTML，搜索、分页、删除、分配角色、禁用/启用、重置密码等功能全部缺失，页面属于未完成状态。

### 1.2 补齐目标

1. 实现完整的「新增用户」弹窗表单（用户名/邮箱/初始密码/角色多选），提交后真实新增记录。
2. 实现完整的用户管理操作闭环：编辑、重置密码、禁用/启用、删除。
3. 补齐搜索、角色筛选、状态筛选、分页、统计卡片、空态、Toast 反馈。

---

## 3. 新增/编辑用户弹窗设计

### 3.1 弹窗结构

- 宽度 480px，居中，超出可滚动
- Header（标题动态：`新增用户` / `编辑用户 — {username}`）+ 关闭按钮
- Body：表单字段 + 角色胶囊多选
- Footer：`取消` / `创建用户`（编辑时为 `保存修改`）

### 3.2 表单字段

| 字段 | 控件 | 必填 | 校验规则 |
|------|------|------|---------|
| 用户名 | 文本输入 | ✅ | 字母开头，仅字母/数字/下划线，2-50 位；唯一 |
| 邮箱 | 邮箱输入 | ✅ | 标准邮箱格式；唯一 |
| 初始密码 | 密码输入 | ✅（仅新增） | 至少 8 位 |
| 角色 | 胶囊多选 | ✅ | 至少选 1 个 |

**编辑模式差异**：用户名字段置为只读（用户名不可改）、密码字段隐藏（编辑不改密码，另设「重置密码」入口）、标题与按钮文案切换。

### 3.3 角色胶囊多选

- 可选角色：`运营人员（data_scope: all）`、`普通用户（data_scope: self）`
- `超管（系统保留）` 以禁用态展示，不可选
- 选中态：琥珀色边框 + 琥珀浅底 + 深琥珀文字
- 支持多选，符合 RBAC 用户-角色多对多模型

### 3.4 数据范围联动

数据范围不单独填写，由所选角色自动推导（与后端 `data_scope` 判定逻辑一致）：

| 推导结果 | 标签样式 | 条件 |
|----------|---------|------|
| `super`（all · 锁定） | 蓝色标签 | `superuser=true` |
| `all` | 琥珀标签 | 任一角色 scope=all（运营人员） |
| `self` | 灰色标签 | 全部角色 scope=self（普通用户） |

## 4. 用户操作设计

### 4.1 行操作

| 操作 | 触发 | 行为 |
|------|------|------|
| 编辑 | 链接按钮 | 打开编辑弹窗回填 |
| 重置密码 | 链接按钮 | 打开重置密码弹窗（新密码 + 确认） |
| 禁用/启用 | 链接按钮 | 切换状态 + Toast |
| 删除 | 链接按钮（红） | `confirm` 二次确认后删除 + Toast |

**当前账号（超管）**：操作列显示「当前账号」占位，不提供编辑/重置/禁用/删除，避免误操作锁死系统。

### 4.2 重置密码弹窗

- 展示目标用户名
- 新密码 + 确认密码两个字段
- 校验：至少 8 位、两次一致

### 4.3 表单校验

| 校验项 | 提示文案 |
|--------|---------|
| 用户名为空 | 请填写用户名 |
| 用户名格式错 | 用户名需以字母开头，仅含字母/数字/下划线，2-50 位 |
| 邮箱格式错 | 请填写有效的邮箱地址 |
| 密码过短 | 初始密码至少 8 位 |
| 未选角色 | 请至少分配一个角色 |
| 用户名重复 | 该用户名已存在 |
| 邮箱重复 | 该邮箱已被使用 |

## 5. 列表交互设计

### 5.1 工具栏

- 关键词搜索：用户名/邮箱模糊匹配（`input` 即时触发）
- 角色筛选：全部/超管/运营人员/普通用户
- 状态筛选：全部/活跃/已禁用
- 任一筛选变化重置到第 1 页

### 5.2 统计卡片

三张卡片实时联动：用户总数 / 活跃用户（绿）/ 已禁用（红），顶部彩色装饰条区分。

### 5.3 头像

按用户 ID 取模分配 6 种渐变头像色（蓝/绿/紫/琥珀/玫红/青），显示用户名首字母大写。

### 5.4 分页

- 每页 5 条
- 上一页/下一页按钮 + 页码指示（`当前页 / 总页数`）
- 边界禁用

### 5.5 空态

无匹配时显示居中空态：👤 图标 + 「未找到匹配的用户」+ 引导文案。

---

## 6. 设计亮点

1. **数据范围自动推导**：不设独立字段，由角色推导，与后端 `data_scope` 判定逻辑保持一致，避免前后端数据不一致。
2. **超管系统保护**：当前账号不显示破坏性操作，`超管` 角色在分配时以禁用态展示，防止越权/误操作。
3. **编辑与新增模式复用**：同一弹窗通过 `editingId` 区分模式，只读字段与隐藏字段按需切换，减少重复 UI。
4. **胶囊多选角色**：替代原下拉单选，契合 RBAC 用户-角色多对多关系，直观展示 data_scope。
5. **统计卡片实时联动**：新增/删除/禁用后，顶部三项统计即时更新。

## 8. 技术规范

- **实现方式**：纯 HTML5 + CSS3 + Vanilla JavaScript，无外部依赖
