# 辰光Agent平台 RBAC授权模块 — UI原型设计说明书

> 本文档描述 RBAC 授权功能的页面原型设计，配合 [PROJECT_SPEC_V2.md](../../spec/PROJECT_SPEC_V2.md) 需求文档使用。

---

## 1. 设计概述

### 1.1 设计目标

为辰光 Agent 平台 RBAC 授权功能（功能权限 + 两档数据范围）提供可视化的页面原型，覆盖以下核心场景：

1. **登录** — 展示超管身份、权限码列表、数据范围预览
2. **工作台** — 展示当前用户授权状态、资源概览
3. **角色管理** — 角色列表、数据范围配置、权限分配
4. **权限管理** — 43 个权限码清单、模块分类、创建/编辑
5. **用户管理** — 用户列表、角色分配、数据范围配置

### 1.2 设计语言

| 元素 | 规范 |
|------|------|
| 主色 | `#0F172A` 深海军蓝（导航、按钮、强调） |
| 辅助色 | `#F59E0B` 琥珀金（品牌、高亮、徽章） |
| 背景 | `#F8FAFC` 浅灰蓝（页面背景） |
| 表面 | `#FFFFFF` 纯白（卡片、表格） |
| 文字 | `#0F172A` 深海军蓝（主文字）/ `#64748B` 中灰（次要）/ `#94A3B8` 浅灰（提示） |
| 字体 | Inter / Noto Sans SC（无衬线，现代感） |
| 圆角 | 8px（卡片）/ 6px（输入框、按钮） |
| 间距 | 4px 基准，8/16/24/28 常用间隔 |

**设计原则：**
- 深色侧边栏 + 浅色内容区的经典企业后台布局
- 授权状态（超管/数据范围）在顶部和侧边栏均有明确标识
- 权限码以 `code` 样式（等宽字体 + 背景色）呈现，强化技术属性
- 操作按钮按权限等级配色（主操作深蓝、危险操作红色、次要操作灰色）

## 3. 页面详细说明

### 3.1 登录页（login.html）

**布局结构：**
- 左侧品牌面板（440px 固定宽度，深海军蓝背景）：Logo + 产品名称 + 核心价值文案 + 功能特性列表
- 右侧登录表单（自适应宽度）：用户名/密码/验证码输入 + 登录按钮

**设计亮点：**
- 登录表单下方展示"登录将获得的权限"预览卡片，以标签形式列出 13 个代表性权限码，其中数据范围 `all` 以琥珀色高亮
- 验证码图片模拟为深蓝色渐变背景 + 琥珀色随机字符

**交互说明：**
- 点击验证码图片可刷新（模拟）
- 登录按钮点击后跳转至工作台

---

### 3.2 工作台（dashboard.html）

**布局结构：**
- 左侧固定侧边栏（240px）：导航菜单（工作台/Agent管理/分析/系统管理）
- 顶部面包屑导航条：工作台 / 概览 + 超管模式徽章
- 主内容区：授权信息横幅 + 统计卡片 + 快捷入口 + 最近创建资源表格

**设计亮点：**
- **授权信息横幅**：左侧金色盾牌图标，中间显示当前身份（"管理员 admin"）及权限描述，右侧展示权限标签（`superuser` / `data_scope: all` / `43/43 权限`）
- **统计卡片**：四列网格（Agent总数/知识库/活跃用户/今日对话），每张卡片顶部有彩色装饰条（琥珀/蓝/绿/紫）
- **快捷入口卡片**：三列网格（角色管理/权限码清单/用户管理），悬停时边框变琥珀色

**交互说明：**
- 侧边栏当前激活项（工作台）以琥珀色高亮 + 左侧琥珀色竖线标识
- 快捷卡片可点击跳转到对应管理页面

---

### 3.3 角色管理（roles.html）

**布局结构：**
- 侧边栏（同上）
- 顶部面包屑：工作台 / 系统管理 / 角色管理 + 超管模式徽章
- 主内容区：页面标题 + 创建角色按钮 + 统计卡片 + 角色列表表格

**设计亮点：**
- **超管角色行**：背景浅灰（`#F8FAFC`）区分，显示 `system` 徽章 + `🔒 只读` 标识，操作列显示锁图标
- **数据范围标签**：
  - `all` → 琥珀色背景（`#FEF3C7` + `#92400E` 文字）
  - `self` → 灰色背景
  - 锁定状态 → 蓝色背景（`#DBEAFE` + `#1E40AF` 文字）
- **统计卡片**：三列（角色总数/全量数据角色/仅本人数据角色）

**弹窗交互：**
1. **创建角色弹窗**：角色名称 + 编码 + 数据范围下拉（self/all）+ 描述
2. **分配权限弹窗**：搜索框 + 已选数量 + 权限复选框列表（含超管专属权限禁用状态）

---

### 3.4 权限管理（permissions.html）

**布局结构：**
- 侧边栏（同上）
- 顶部面包屑：工作台 / 系统管理 / 权限管理 + 超管模式徽章
- 主内容区：页面标题 + 创建权限按钮 + 统计卡片 + 权限列表表格

**设计亮点：**
- **模块分类标签栏**：水平滚动标签（全部/user/role/permission/agent/model/provider/prompt/knowledge/tool），当前激活标签底部琥珀色下划线
- **权限码展示**：使用等宽字体 + 浅灰背景 + 细边框，格式 `模块:操作`
- **操作类型徽章**：查看（蓝）/ 创建（绿）/ 编辑（蓝）/ 删除（红）/ 专属（紫）
- **模块徽章**：不同模块不同颜色（user=琥珀/role=紫/agent=蓝/knowledge=绿/model=蓝/tool=灰）

**弹窗交互：**
- **创建权限弹窗**：权限编码（格式提示）+ 权限名称 + 描述

---

### 3.5 用户管理（users.html）

**布局结构：**
- 侧边栏（同上）
- 顶部面包屑：工作台 / 系统管理 / 用户管理 + 超管模式徽章
- 主内容区：页面标题 + 创建用户按钮 + 用户列表表格

**设计亮点：**
- **用户头像**：圆形渐变色头像（蓝/绿/紫/琥珀），首字母大写
- **当前账号行**：浅灰背景高亮，操作列显示"当前账号"标识
- **角色徽章**：单角色直接显示，多角色以药丸（pill）组展示
- **数据范围标签**：与角色管理页一致（all=琥珀/self=灰/锁定=蓝）
- **状态徽章**：活跃（绿）/ 已禁用（红）

**弹窗交互：**
1. **创建用户弹窗**：用户名 + 邮箱 + 密码 + 角色选择（含数据范围说明）
2. **分配角色弹窗**：当前角色展示（含数据范围）+ 角色选择 + 确认提示

## 4. 授权信息可视化规范

### 4.1 数据范围标签

| 状态 | 样式 | 使用场景 |
|------|------|----------|
| `all`（全部数据） | 琥珀色背景 + 深色文字 | 数据范围 = all |
| `self`（仅本人） | 灰色背景 + 中灰文字 | 数据范围 = self |
| `superuser` | 蓝色背景 + 深色文字 | 超管身份标识 |
| 锁定 | 蓝色背景 + 深色文字 + "锁定"后缀 | 超管角色不可修改 |
| 组织级 | 蓝色背景 + 深色文字 | 模型/供应商等共享资源 |

### 4.2 权限码标签

- 格式：`模块:操作`（如 `agent:view`）
- 样式：等宽字体、浅灰背景、1px 边框、4px 圆角、11px 字号
- 颜色：默认深灰（`#64748B`）

### 4.3 操作按钮层级

| 按钮类型 | 背景色 | 文字色 | 使用场景 |
|----------|--------|--------|----------|
| 主操作 | `#0F172A` 深海军蓝 | `#FFFFFF` | 创建、保存、确认 |
| 次要操作 | `#FFFFFF` 白 + 边框 | `#64748B` 中灰 | 取消、重置 |
| 危险操作 | `#FEF2F2` 浅红 | `#EF4444` 红色 | 删除、禁用 |
| 链接操作 | 透明 | `#3B82F6` 蓝色 | 编辑、查看 |

## 6. 技术规范

### 6.1 技术栈

- **框架**：纯 HTML5 + CSS3 + Vanilla JavaScript（无外部依赖）
- **字体**：Google Fonts (Inter + Noto Sans SC)
- **图标**：Lucide Icons (SVG inline)
- **截图工具**：Microsoft Edge Headless Mode

### 6.2 兼容性

- 现代浏览器（Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+）
- 分辨率：1440x900（桌面端标准）

### 6.3 文件命名

- HTML：`<page-name>.html`（kebab-case）
- PNG：`<page-name>.png`（kebab-case）
- 设计文档：`rbac-ui-design.md`
